# 채팅별 연결 프로필 · 기본 + 예외

SillyTavern **1.18.0 / 1.19.0**용 독립 서드파티 확장입니다.

**기본 연결 프로필 B를 한 번 설정하고, 특정 개별 채팅에만 예외 연결 프로필 A를 지정합니다.** 예외가 없는 기존·새 채팅으로 이동하면 자동으로 기본 B로 돌아갑니다. JS-Slash-Runner는 필요하지 않습니다.

## 주소로 설치

SillyTavern → **확장(Extensions) → 확장 설치(Install Extension)**에서 아래 주소를 붙여 넣으세요.

```text
https://github.com/minte69-cloud/st-chat-profile-default
```

설치 후 페이지를 새로고침하고 내장 **Connection Profiles / Connection Manager**를 켜세요.

기존 1.0.0에서 최소 버전 오류가 표시되었다면 **확장 관리 → 이 확장 업데이트** 후 페이지를 새로고침하세요. 1.0.1은 1.18.0부터 로드됩니다.

**1.0.2:** 정규식 설정이 포함된 프로필 전환 중 채팅 다시 불러오기와 서로 대기하던 문제를 수정했습니다. 채팅을 나간 홈/최근 채팅 화면에서는 전환하지 않고, 다음 실제 채팅을 열 때 기본 B 또는 해당 예외 A를 적용합니다. 업데이트 후 반드시 페이지를 새로고침하세요.

## 사용

**1.1.0:** 관리 화면을 확장 설정에서 **요술봉 → 채팅별 연결 프로필**의 별도 창으로 옮겼습니다. 기본값과 채팅 예외는 유지됩니다. 창을 닫아도 자동 전환은 계속됩니다. 업데이트 후 페이지를 새로고침하세요.

1. Connection Manager에 사용할 연결 프로필 A와 B를 미리 저장합니다.
2. 채팅 입력창 옆 **요술봉 → 채팅별 연결 프로필**에서 **기본 연결 프로필 B**를 한 번 선택합니다.
3. 예외를 줄 채팅을 열고 **현재 개별 채팅의 예외 A**를 선택합니다.
4. 다른 미지정 채팅으로 이동하면 B로 돌아갑니다. 같은 캐릭터의 다른 채팅도 별도로 취급합니다.
5. 예외를 해제하려면 **예외 없음 → 기본 B 사용**을 선택합니다.

제어 대상은 **연결 프로필**입니다. 연결 프로필에 저장된 모델·API·프리셋 등은 SillyTavern의 기본 동작대로 함께 적용됩니다. 기존 채팅마다 B를 지정할 필요는 없습니다.

전환이 끝나고 SillyTavern의 연결 상태가 정상인지 확인한 뒤 답변을 생성하세요. 다른 스크립트가 `/profile`을 자동 실행한다면 해당 자동 전환은 꺼 주세요. 실제 사용자 서버·API 실접속은 아직 검증하지 않았으며 모의 환경 검사 15개를 통과했습니다.

ZIP으로 먼저 수동 설치했다면 기존 확장을 비활성화하고 페이지를 새로고침한 뒤 기존 `chat-profile-default` 설치 폴더를 삭제하고 주소로 설치하세요. 같은 확장을 두 개 동시에 설치하지 마세요. 이 확장 자체 설정 키는 같으므로 같은 계정의 저장된 기본값·채팅 예외를 계속 사용합니다.
